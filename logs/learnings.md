###### 2026-08-20 yt-dlpの403エラーとバージョン更新

YouTubeの動画情報（タイトル・サムネイルなど）は取得できるのに、実際のダウンロード時だけ `HTTP Error 403: Forbidden` になることがある。これは、YouTube側が配信方法（暗号化やアクセス許可の仕組み）を頻繁に変更しており、ダウンロードに使っているツール「yt-dlp」がその変更に追いついていないと起きる典型的な症状。yt-dlpはほぼ毎週〜隔週でアップデートされており、動画情報の取得（軽い処理）は多少古いバージョンでも動くが、実際のダウンロード（重い処理）はYouTube側の最新仕様に対応していないと弾かれやすい。対処法は `pip install --upgrade yt-dlp` で最新版に更新すること。

###### 2026-08-20 .gitignoreとgit add -f

`.gitignore` に書かれたパターン（例：`logs/`）に一致するファイルは、`git add` や `git status` で通常は無視される。ただし `git add -f`（forceオプション）を使うと、`.gitignore`のルールを一時的に無視して特定のファイルを強制的にステージング（コミット対象に追加）できる。今回はプロジェクトの設計上「ログはGit管理外」という方針だったが、ユーザーの明示的な指示で今回限り例外的に含めた。

###### 2026-10-02 アプリの「初期値」と「保存済みの値」の違い

iPhoneアプリの設定値（今回は接続先URL）は、端末内の `UserDefaults` という保存領域に記録される。コード上の初期値（`?? "http://...local:5001"` の部分）が使われるのは、まだ何も保存されていない場合だけ。一度でも設定画面で値を入力すると、その値が優先される。この値はアプリをアップデートしても消えない。そのため、アプリ側で初期値を変えても既存ユーザーには反映されない。既存ユーザーにも反映するには、起動時に古い値を検出して書き換える「移行処理」が別途必要になる。
