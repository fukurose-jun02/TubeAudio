# YouTube動画キーワード検索機能 - 要件定義書

関連Issue: https://github.com/fukurose-jun02/TubeAudio/issues/8

###### 背景・課題

- 現状、動画を変換するには事前にYouTubeアプリ等でURLを調べてコピーし、TubeAudioに貼り付ける必要がある
- 「あの動画を音声化したい」と思ってから実際に変換するまでの手間が大きい
- サーバー（Mac）は既にyt-dlpに依存しているが、検索は非対応

###### ゴール

- iOSアプリ内でキーワード検索から動画を選び、そのまま変換まで完結できるようにする
- 既存の変換フロー（`/api/info` → `/api/convert` → ポーリング → ダウンロード）は変更せず、検索は「URL入力の代替手段」として追加する

###### 非ゴール（今回のスコープ外）

- 再生履歴や検索履歴の保存
- チャンネル単位の検索・購読
- ページネーション（2ページ目以降の追加読み込み）は初期スコープ外。1回の検索で最大20件を表示する
- 動画以外（再生リスト・チャンネル・ライブ配信）の検索

###### 機能要件

| ID | 内容 |
|---|---|
| F1 | 新しい「検索」タブを追加し、キーワード入力欄と検索結果一覧を表示する |
| F2 | 検索結果には サムネイル・タイトル・チャンネル名・（取得できれば）再生時間 を表示する |
| F3 | 検索結果の項目をタップすると、そのURLで自動的に変換フロー（`/api/info`→`/api/convert`）を開始する |
| F4 | 検索はYouTube Data API v3の`search.list`をサーバー経由で呼び出す（iOSから直接APIは呼ばない） |
| F5 | 検索APIキー未設定・クォータ超過・通信エラー時は、原因が分かるエラーメッセージを表示する |

###### 非機能要件

- **セキュリティ**: YouTube Data APIキーはMacサーバー側の環境変数のみで保持し、iOSアプリのバイナリ・リポジトリに含めない
- **コスト**: 無料枠は1日10,000クォータ、`search.list`は1回100消費 → 1日あたり約100回の検索が可能。個人利用の想定範囲内
- **既存機能への影響**: 変換タブ・ライブラリタブ・設定タブの既存動作を変更しない

###### 受け入れ基準

- [x] 検索タブでキーワードを入力すると、YouTube Data APIから取得した結果が一覧表示される
- [x] 結果をタップすると変換が自動的に開始し、完了後ライブラリに保存される
- [ ] サーバー側にAPIキーを設定していない状態で検索すると、分かりやすいエラーメッセージが出る（コードレビューで確認済み、実機での動作確認は未実施）
- [x] 既存の「変換」タブからのURL手動入力フローは従来どおり動作する（変更なし）

###### ヒアリング済みの決定事項

| 論点 | 決定 |
|---|---|
| 検索UIの配置 | 新しい「検索」タブを追加 |
| 検索結果タップ時の挙動 | URLを自動入力し、即座に変換を開始する |
| APIキーの管理場所 | サーバー（Mac）側の環境変数のみ |
