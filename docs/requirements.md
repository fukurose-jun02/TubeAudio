# YouTube共有メニューからのURL取り込み - 要件定義書

関連Issue: https://github.com/fukurose-jun02/TubeAudio/issues/17

###### 背景・課題

- 聴きたい動画を見つけるたびに、YouTubeでURLをコピーし、TubeAudioの入力欄に貼り付ける必要があり、手間になっている

###### ゴール

- YouTubeアプリの共有メニューに「TubeAudio」が表示され、選ぶだけでURLがアプリに渡る
- アプリを開くと、URLが入力済みになり、動画情報の取得まで自動で進んでいる

###### 非ゴール（今回のスコープ外）

- 共有した時点でMacへ変換を依頼すること（アプリを開く前に変換を始める案。将来の拡張候補）
- 共有後にアプリを自動で起動すること（iOSの仕様上、拡張機能からの起動に公式手段がないため）
- 外出先（別ネットワーク）からのアクセス対応
- 7日で署名が切れる問題への対応（別途保留中）

###### 機能要件

| ID | 内容 |
|---|---|
| F1 | YouTubeアプリ・Safariなどの共有メニューに「TubeAudio」が表示される |
| F2 | 共有されたURLがYouTube（youtube.com / youtu.be / m.youtube.com / music.youtube.com）のものであれば受け付け、共有画面に「追加しました」と表示して閉じる |
| F3 | YouTube以外のURL・URLを含まない共有は受け付けず、共有画面にその旨を表示する |
| F4 | アプリが起動または前面に戻ったとき、受け取り済みのURLがあれば「変換」タブを開き、入力欄に入れて動画情報の取得まで自動で実行する |
| F5 | 受け取り済みのURLは1回使ったら消す（再起動のたびに同じURLが入らないようにする） |
| F6 | 共有テキストに説明文とURLが混ざっている場合（例:「動画名 https://youtu.be/xxx」）はURL部分だけ取り出す |

###### 非機能要件

- **既存機能への影響なし**: 変換・検索・ライブラリ・再生の動作は変えない
- **Mac側の変更なし**: サーバー・APIは変更しない
- **前提**: 変換にはこれまでどおりMacと同じWiFiが必要
- **バージョン**: アプリのバージョンを1.08→1.09に更新し、設定画面に表示する

###### 受け入れ基準

- [ ] iOS Simulator用ビルドが成功する
- [ ] アプリ本体にApp Groupの権限が付き、拡張機能がアプリに同梱される（ビルド成果物で確認）
- [ ] 保管場所にURLを書いた状態でアプリが前面に来ると、変換タブに切り替わり入力欄に入る（Simulatorで確認）
- [ ] 実機のYouTubeアプリの共有メニューに「TubeAudio」が表示され、共有したURLが入力欄に入る（ユーザーが実機で確認）
