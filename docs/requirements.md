# ライブラリのラジオ/BGM分類 - 要件定義書

関連Issue: https://github.com/fukurose-jun02/TubeAudio/issues/21

###### 背景・課題

- ライブラリにはこれまでラジオ(話し言葉の音声)だけが入っていたが、今後BGMも入れたい
- 種類が混ざると、聴きたい音声を探しにくくなる

###### ゴール

- 音声が「ラジオ」「BGM」の2カテゴリに分かれ、ライブラリの上部で切り替えて見られる
- 変換するときにカテゴリを選べる
- 保存した後でも、カテゴリを移し替えられる

###### 非ゴール(今回のスコープ外)

- BGMだけの再生挙動の変更(ループ再生、再生位置を覚えない、など)
- 3つ目以上のカテゴリ、ユーザーによるカテゴリの追加・名前変更
- Mac側サーバー・APIの変更

###### 機能要件

| ID | 内容 |
|---|---|
| F1 | 変換画面に「ラジオ / BGM」の切り替えを置く。初期値は「ラジオ」 |
| F2 | 変換が完了した音声は、選ばれたカテゴリで保存される |
| F3 | ライブラリ画面の上部に「ラジオ / BGM」の切り替えを置き、選んだカテゴリの音声だけを表示する |
| F4 | 既存の「すべて / 未再生」の絞り込みと並び順は、選んだカテゴリの中で従来どおり使える |
| F5 | ライブラリの各音声で、長押しメニューとスワイプ操作から、もう一方のカテゴリへ移せる |
| F6 | カテゴリが未設定の既存の音声(メタデータなし・カテゴリ項目なしを含む)は、すべて「ラジオ」として扱う |
| F7 | カテゴリ内に音声がない場合、そのカテゴリが空であることを表示する |

###### 非機能要件

- **既存機能への影響なし**: 変換・検索・共有拡張・再生・再生位置の記憶は変えない
- **既存データの互換**: 保存済みのメタデータが読めなくならない(カテゴリ項目は省略可能にする)
- **Mac側の変更なし**
- **バージョン**: アプリのバージョンを1.10→1.11に更新し、設定画面に表示する

###### 受け入れ基準

- [ ] iOS Simulator用ビルドが成功する
- [ ] 変換時にBGMを選ぶと、ライブラリの「BGM」側にだけ表示される
- [ ] 既存の音声が「ラジオ」側にすべて表示される(アップデート後も消えない)
- [ ] 移し替えで、音声がもう一方のカテゴリに移り、再生位置や未再生の状態は変わらない
- [ ] 音声を削除しても、他のカテゴリの音声に影響しない
