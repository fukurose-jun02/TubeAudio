###### 実装ステップ

1. ブランチ`feature/21-library-categories`を作る
2. `LibraryMetadataStore.swift`に`AudioCategory`と取得・設定の関数を足す
3. `ContentView.swift`の`ConvertView`にカテゴリ選択を足し、保存時に渡す
4. `LibraryView`に上部の切り替え・絞り込み・移し替え(長押しメニューとスワイプ)・空表示を足す
5. バージョンを1.11にし、`ios/README.md`を更新する
6. Simulator用にビルドし、既存データが「ラジオ」に出ることを確認する
7. PRを作り、ユーザーの実機確認の結果に応じてこの文書を完了状態へ更新する

###### 確認のポイント(実機)

- アップデート後、今ある音声がすべて「ラジオ」に表示されるか
- 変換時にBGMを選ぶと、BGM側にだけ出るか
- 移し替えても再生位置・未再生の状態が変わらないか
